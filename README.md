# A/B-тест: реклама против PSA на реальных данных

Анализ открытого эксперимента [Marketing A/B Testing](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing) (Kaggle, лицензия CC0 1.0): 588 101 пользователь, две группы — реклама (`ad`) и публичное объявление-заглушка (`psa`). Метрика — конверсия.

В кейсе: проверка дизайна и баланса групп, тест на конверсию с доверительным интервалом, сегменты по дням и часам с поправкой на множественные сравнения, анализ «дозы» показов и честные ограничения.

## Данные

| Поле | Описание |
|---|---|
| `user_id` | идентификатор пользователя |
| `group` | `ad` — видел рекламу, `psa` — видел объявление-заглушку (holdout) |
| `converted` | 1 — конверсия состоялась |
| `total_ads` | сколько рекламных показов получил пользователь |
| `day`, `hour` | день недели и час наибольшей активности |

Размер: 588 101 строка. Разделение: `ad` — 564 577 (96.0 %), `psa` — 23 524 (4.0 %). Пропусков и дублей пользователей нет.

Подготовка (`scripts/prepare_data.py`) переименовывает колонки, приводит флаг конверсии к 0/1 и сохраняет компактный CSV. Исходные данные скачиваются скриптом `scripts/download_data.py` с проверкой контрольной суммы.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python3 scripts/download_data.py   # ~5 МБ
python3 scripts/prepare_data.py
jupyter lab ab_test_analysis.ipynb
```

## Дизайн

| Параметр | Значение |
|---|---|
| Первичная метрика | конверсия |
| α | 0.05, двусторонний |
| Мощность | 0.80 |
| Базовая конверсия | ≈1.8 % (`psa`) |
| Целевой MDE | 0.5 п.п. |
| Требуемая выборка | ≈12 600 на группу |

Гипотезы: H₀ — конверсия в группах одинакова; H₁ — различается.

## Результаты

### Проверка дизайна

SRM против 50/50 ожидаемо не проходит: χ² = 497 769, p < 10⁻³⁰⁰. Это не ошибка рандомизации, а holdout-дизайн: 4 % аудитории оставили без рекламы. Доля `psa` по дням держится в диапазоне 3.5–4.7 %, то есть назначение стабильно.

### Первичная метрика

| Метрика | `ad` | `psa` | Разница |
|---|---:|---:|---:|
| Конверсия | 2.55 % | 1.79 % | +0.77 п.п. |
| 95 % ДИ разницы | — | — | [+0.60; +0.94] п.п. |
| Относительный рост | — | — | +43.1 % |
| z | — | — | 8.66 |
| p-value | — | — | 4.8 × 10⁻¹⁸ |
| h Кохена | — | — | 0.053 |

Эффект статистически значим и устойчив: интервал не включает ноль. При этом h Кохена малый — в абсолютных пунктах прирост меньше процента, но относительно низкой базовой конверсии он substantial: +43 %.

### Баланс групп

Среднее число показов: 24.82 в `ad` и 24.76 в `psa`, стандартизованная разница средних SMD = 0.0014 — отличный баланс (порог 0.1). Манн—Уитни при этом даёт p ≈ 5 × 10⁻¹¹: на 588 тысячах наблюдений значимыми становятся различия в сотые доли. Поэтому баланс оценивается по размеру эффекта, а не по p-value.

### Сегменты по дням недели

| День | Разница, п.п. | p после Холма |
|---|---:|---:|
| Вторник | +1.60 | < 0.001 |
| Понедельник | +1.07 | 0.0002 |
| Среда | +0.96 | 0.0001 |
| Суббота | +0.73 | 0.005 |
| Пятница | +0.62 | 0.011 |
| Воскресенье | +0.40 | 0.250 |
| Четверг | +0.14 | 0.543 |

Эффект есть в большинстве дней, но колеблется от +0.14 до +1.60 п.п. После поправки на семь сравнений четверг и воскресенье не значимы — говорить «эффект сильнее во вторник» нельзя без отдельного теста взаимодействия.

### Сегменты по времени суток

| Интервал | Разница, п.п. | p после Холма |
|---|---:|---:|
| Ночь 0–5 | +1.21 | < 0.001 |
| Утро 6–11 | +0.86 | < 0.001 |
| День 12–17 | +0.75 | < 0.001 |
| Вечер 18–23 | +0.68 | < 0.001 |

Все четыре интервала значимы после поправки. Ночной эффект самый большой, но там мало пользователей и широкий интервал.

### Доза показов

| Показов | Пользователей | Конверсия |
|---|---:|---:|
| 1–5 | 169 962 | 0.25 % |
| 6–15 | 146 101 | 0.61 % |
| 16–40 | 160 056 | 1.83 % |
| 41+ | 88 458 | 11.50 % |

Конверсия растёт с числом показов в 46 раз между крайними группами. Это сильная связь, но **не причинный эффект**: показы не назначались случайно, их больше получают активные пользователи. Переменная пост-обработки — годится как описательная закономерность и повод для отдельного эксперимента, но не как оценка эффекта рекламы.

### Чувствительность

Фактический MDE при текущей выборке — 0.25 п.п., наблюдаемый эффект 0.77 п.п. — в 3.1 раза больше. Эксперимент был достаточно мощным, чтобы поймать эффект такого размера.

## Что демонстрирует кейс

- расчёт размера выборки до анализа и проверка достигнутой чувствительности;
- корректная работа с неравным разделением групп: holdout вместо «сломанного SRM»;
- z-тест для долей и доверительный интервал для разницы;
- размер эффекта (h Кохена) в дополнение к p-value и предупреждение о p-value на больших выборках;
- поправка Холма при сегментном анализе;
- различение причинного эффекта и пост-обработочной связи (доза показов);
- явные ограничения: нет выручки, CAC и guardrail-метрик.

## Ограничения

- Нет выручки и стоимости привлечения: нельзя посчитать ARPU, ROI и окупаемость.
- Нет guardrail-метрики: рост нагрузки на поддержку или возвратов не проверить.
- Разделение 96/4, а не 50/50: в узких сегментах погрешность выше.
- «Число показов» — переменная после рандомизации, причинный вывод по ней невозможен.
- Нет временных меток пользователя: устойчивость эффекта во времени не проверена.
- Одна рекламная кампания: перенос выводов на другие кампании и каналы не обоснован.
